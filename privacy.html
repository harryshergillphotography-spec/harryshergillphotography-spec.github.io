Privacy Policy — Harry Uploader

Last updated: 3 November 2026

Harry Uploader is a private tool used only by Harry Shergill to upload videos, thumbnails and metadata to YouTube channels he owns. It is not offered to the public.

Data we access

With your permission through Google sign-in, the app uses the YouTube Data API to upload videos, set titles, descriptions, tags and thumbnails, manage playlists, and read basic channel and video statistics for the channel you authorize.

How data is stored

Authorization tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. Data is used only to perform the uploads and updates you request.

YouTube

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy. You can revoke access anytime at Google security settings.
